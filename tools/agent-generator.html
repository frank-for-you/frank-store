What are SOUL.md, AGENTS.md and MEMORY.md?

      
AI agents forget everything between sessions unless you give them files to read. A small set of plain-markdown files has become a common convention for this: the agent loads them at the start of each session, so identity, rules and context carry over without any special infrastructure.

      
SOUL.md — who the agent is

      
SOUL.md defines persona: the name, purpose, tone and core principles. It keeps behavior consistent across sessions and across models. The best SOUL files are short and specific — lines like “never act irreversibly without asking” change behavior, while “be helpful” does not.

      
AGENTS.md — how the agent works

      
AGENTS.md holds workspace rules: what to read on startup, how to use tools, a recall-before-asking rule (search memory before asking you something you may have already answered), the memory protocol for writing things down, and safety boundaries for destructive or external actions.

      
MEMORY.md — what the agent knows

      
MEMORY.md is a pointer index, not a diary. Each line is a durable fact or a link to a longer note. Keeping it short means it fits in context every session, while detail lives in daily notes or topic files that the agent searches on demand.
