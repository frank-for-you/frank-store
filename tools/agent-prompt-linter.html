What makes a good agent instruction file?

An AGENTS.md, CLAUDE.md or system prompt is the only thing standing between a capable model and your files, accounts and budget. The files that work well say who the agent is, what done looks like, what it must ask before doing, how it remembers, and what to do when it gets stuck.

What this linter checks

Fourteen rules covering identity, success criteria, safety boundaries, memory, vague wording, contradictory always/never pairs, length, output format, tool guidance, failure behavior, hard-coded secrets and prompt-injection exposure. Each finding has a severity, a reason it matters and a one-line fix. The checks are pattern-based, so treat the score as a checklist, not a verdict.
