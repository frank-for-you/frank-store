What is MCP?

The Model Context Protocol (MCP) is an open protocol, introduced by Anthropic, that lets AI apps connect to external tools and data through small servers. An MCP client such as Claude Code, Claude Desktop or Cursor starts or connects to each server you list in its config, asks what tools it offers, and lets the model call them: read files, query a database, drive a browser, look up library docs.

Most local servers are launched as a command (npx, uvx, node, python) that talks to the client over stdio. Remote servers are reached by url over HTTP or SSE instead. Either way, the config is a JSON object under a top-level mcpServers key.

Where the config file lives

  • Claude Code: .mcp.json in your project root for project scope (shareable through git; Claude Code asks you to approve project servers). Local and user scope are stored in ~/.claude.json and are managed with claude mcp add. Run /mcp inside Claude Code to see server status.
  • Claude Desktop: claude_desktop_config.json. On macOS: ~/Library/Application Support/Claude/. On Windows: %APPDATA%\Claude\. You can also open it from Settings, Developer, Edit Config.
  • Cursor: .cursor/mcp.json in a project, or ~/.cursor/mcp.json for all projects.

Config locations and supported fields change between releases, so check your client's documentation if something here does not match what you see.

5 common MCP config mistakes

  1. Using bare npx on native Windows. Some clients cannot launch npx directly there. Use "command": "cmd" with "args": ["/c", "npx", "-y", ...]. The builder has a checkbox for this.
  2. Leaving out -y. Without it, npx may stop to ask whether to install the package. The client has no terminal to answer, so the server just hangs or times out.
  3. Relative paths. The client decides the working directory, not you, and ~ is usually not expanded in args. Use absolute paths for directories, databases and scripts.
  4. Not restarting the client. Claude Desktop reads its config at launch, so quit it fully (not just close the window) and reopen. Claude Code and Cursor also need a restart or reload to pick up edited files.
  5. Committing secrets. A token pasted into .mcp.json goes into git history. Keep real values out of shared files: Claude Code supports ${VAR} expansion in .mcp.json, or use user-scope config. If a key was committed, rotate it.

Server packages and flags also change over time. Some of the reference servers have been moved or archived, so check each package's README before relying on it.
