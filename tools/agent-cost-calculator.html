    How AI agent API costs work

    API providers bill per token, with output tokens costing several times more than input tokens. An agent that re-reads a long context on every run pays for that input every time — which is why input size and run count usually dominate the bill, not the length of the answers.

    Prompt caching

    When the start of your prompt (system prompt, memory files, tool definitions) is identical between calls, providers can serve it from cache at roughly a tenth of the normal input price. Keep stable content first and changing content last.

    Scheduled runs add up

    A cron job that fires every hour is 720 runs a month. Most of those jobs (checks, summaries, triage) do not need your most capable model.
