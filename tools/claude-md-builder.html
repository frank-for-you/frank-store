CLAUDE.md generator: what a good file contains

A CLAUDE.md is loaded into Claude Code's context at the start of every session, so it works best as a short briefing for a new teammate: the commands to run, the shape of the repo, the rules that are not obvious from reading the code, and the lines the agent must not cross. Generic advice costs context and adds nothing.

AGENTS.md template

AGENTS.md is a plain Markdown convention for instructions to coding agents, read by a growing number of tools. The structure is the same as CLAUDE.md, which is why this builder produces both from one form. If you use several tools, keep one file as the source of truth and reference it from the others.

File names and loading rules change between releases, so check your tool's documentation for where it looks.

Frequently asked questions

What is a CLAUDE.md file?

CLAUDE.md is a Markdown file in your project root that Claude Code reads at the start of every session. It holds the things the model cannot guess from the code: how to build, test and lint, your conventions, what never to touch, and where things live.

What is the difference between CLAUDE.md and AGENTS.md?

CLAUDE.md is read by Claude Code. AGENTS.md is a vendor-neutral convention read by a growing number of coding agents, including Codex and Cursor. The content is largely the same, so many teams keep one source of truth and point the other at it. This tool generates both from the same form. Check each tool's documentation for the exact files it loads.

How long should a CLAUDE.md be?

Short. Aim for well under 300 lines, and in practice 40 to 120 is plenty. Every line is loaded into context on every session, so long files dilute the rules that matter and some get ignored. Link to deeper docs instead of pasting them.

What should I put in a CLAUDE.md?

Exact build, test and lint commands, a short directory map, code style rules that differ from defaults, explicit never-do guardrails, git and PR conventions, and secrets handling. Leave out generic advice like "write clean code" because the model already tries to do that.

Does this tool upload my file?

No. Generation and scoring run entirely in your browser in JavaScript. Nothing you type or paste is sent anywhere, and there is no tracking. Only the optional email form for the free Starter Pack sends data, and only the email address.

How is the score calculated?

The scorer checks for runnable commands, testing instructions, guardrails, a directory map, sane length, vague filler phrases, secrets and safety rules, and git conventions. Each check carries a weight out of 100 and failed checks come with a concrete fix. It is a heuristic for spotting gaps, not a guarantee of how an agent will behave.
