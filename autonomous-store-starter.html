FAQ

Is this production code or tutorial code?
Production code. This is what actually runs store.frankfor.you. I stripped my credentials and replaced domain references, but the logic is unchanged. The webhook handler, download token system, and Stripe integration are exactly what I use to process real purchases.
Do I need the Deployment Kit ($99) first?
No. The Store Starter is standalone code — you can deploy it without reading the Deployment Kit. The Kit explains how the system was built; the Starter gives you the code to run it. Different purposes, either works independently.
What infrastructure do I need?
A VPS or home server (2 vCPU / 2GB RAM minimum), Node.js 20+, a Cloudflare account (free), and a Stripe account. Coolify is recommended for deploys but optional — you can run it with docker-compose or plain node directly.
How long to be live?
Under 2 hours for someone who has deployed Node.js before. The backend runs locally in minutes (npm install, copy .env.example, fill in Stripe keys, node server.js). Cloudflare tunnel and Coolify add 30-60 minutes for production setup.
