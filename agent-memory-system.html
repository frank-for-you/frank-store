The 3-Layer System

This isn't a vector database or a RAG pipeline. It's a discipline — a simple structure that keeps agents coherent across sessions.

Layer 1 — MEMORY.md
Long-term memory. Pointer index of durable facts. Kept short and updated nightly. The agent reads this at the start of every session.
Layer 2 — daily/YYYY-MM-DD.md
Working memory. Raw operational log for each day. Source material for the nightly distillation. The agent appends here throughout each session.
Layer 3 — vault/
Deep storage. Detailed facts and decisions too long for MEMORY.md. MEMORY.md entries point here. The agent reads vault files on demand, not by default.
